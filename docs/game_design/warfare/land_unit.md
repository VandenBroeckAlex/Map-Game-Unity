## battalion Stats

### Battle stats

| Stat | Description | Note |
| --- | --- | --- |
| Manpower | Number of men in bataillon | Affects losses, morale, firepower scaling, organisation |
| Range | Maximum engagement range  <br>(in battle engine unit) | The range depend on the weapons provided to the bataillon |
| Ranged Attack | Number of attack roll in a turn | Ability to hit in range face while in attack |
| Ranged Defense | Number of defence roll in a turn | Ability to hit in range face while in defence |
| Firepower | Base ranged damage potential | Represents weapons + training |
| Rate of Fire | Dice multiplier for ranged attacks  <br>Or hit multiplier ?  <br>Or removed and add value to firepower instead ? | Muskets 1, rifles 2, MGs 4 |
| Assault Power | Hand-to-hand strength | Used in melee |
| Shock effect | hit moral and organisation ? | Demoralize / DeOrgenize |
| Discipline | Affects morale and accuracy | Impacts criticals and cohesion |
| Defense Value | Ability to resist hits |
| Organization | Cohesion, ability to fight effectively |
| Morale | Willingness to keep fighting |
| Frontage | The space unit take on the front |
| Speed | Distance closed per turn if advancing |
| Maneuver | Initiative / ability to reposition | Ability to move and fire first |
| Reconaissance | /   | give bonus to arty ? |
